# 알람바 Step A2 실물 로봇 체크리스트 (사용자 수행)

> 역할: 알람바 Step A2(ACK / SIL)를 **실제 로봇에서** 확인하는 순서. mock 으로는 `tests/test_alarms.py`, `tests/test_alarm_api.py`, `tests/verify_alarm_ui.py`(브라우저 2개)가 통과했다. 이 문서의 어떤 항목도 아직 실제 로봇에서 실행되지 않았다.
> 규칙 전체는 `../interfaces.md` 6-7절, 계획은 `../prd/Pinky 알람바 개선 — 단계별 PRD.md` Step A2.

> 로봇이 움직일 수 있는 항목은 주변을 비우고 전원 스위치에 손이 닿는 곳에서 한다. 소리는 Step A3 이라 SIL 은 버튼 상태만 확인한다.

통과/실패와 이상한 화면 캡처, 백엔드 로그(`backend`: `알람 ACK: [...] (계정)`)를 알려 주면 된다.

## 사전 조건
- [ ] A1 체크리스트의 알람 발생/해소가 통과했다.
- [ ] 관제 PC: `export ROS_DOMAIN_ID=50` 후 `.venv/bin/python -m backend.main` (**`--mock` 없이**).
- [ ] 브라우저 **두 개**를 열어 한쪽은 `mngr`, 다른 쪽은 시크릿 창에서 `oper` 로 로그인한다 (`http://localhost:8000/`).

## A. ACK

| # | 항목 | 방법 | 기대 | 결과 |
|---|---|---|---|---|
| 1 | 대상 없음 | 알람이 없는 상태에서 상단 버튼 확인 | `ACK`, `SIL` 이 회색(비활성). 툴팁: "Acknowledge cleared alarms" / "Silence current alarm sound" | |
| 2 | 활성 알람 ACK | 로봇 한 대의 전원을 꺼 `... 오프라인`(활성)을 만든 뒤 한쪽에서 `ACK` | 알람이 **사라지지 않고** `Acknowledged oper 12:03:01` 처럼 계정·시각이 붙는다. **두 화면 모두**. `ACK`, `SIL` 비활성 | |
| 3 | ACK 한 활성 알람의 해소 | 로봇을 다시 켠다 | 오프라인 행이 두 화면에서 모두 사라지고 `... 온라인`(info)만 남는다 | |
| 4 | 해소된 알람 ACK | 브리지를 끄고 `순찰 정지`(실패 알람) → 브리지를 켜고 `순찰 정지`(해소) → 다른 쪽 화면에서 `ACK` | `Cleared` 상태 행이 **두 화면에서 모두 사라진다**. 활성 알람은 그대로 | |
| 5 | ACK 전 반복은 묶음 | 브리지를 끈 채 `비상 정지`를 두 번 | `비상정지 실패` 가 **한 행**에 `×2` 로 묶인다 | |
| 6 | ACK 후 새 발생 | 5번 알람을 ACK 한 뒤 `비상 정지` 한 번 더 | ACK 한 행(`확인됨`, `×2`)은 그대로 두고 ACK 표시가 없는 **새 행**이 생기며 `ACK`, `SIL` 이 다시 켜진다 | |
| 6-1 | 해소 후 새 발생 | 브리지를 켜고 `비상 정지`(해소) → 다시 끄고 `비상 정지` | 해소된 행과 별개의 새 행이 생긴다 | |
| 7 | 새 화면 | 세 번째 탭을 연다 | ACK 로 숨긴 알람은 보이지 않고, ACK 한 활성 알람은 `확인됨 ...` 로 보인다 | |
| 8 | 서버 재시작 | 서버를 껐다 켠다 | 화면의 알람은 비지만 이력 파일에는 남아 있다 (C 참고) | |

## B. SIL (소리는 A3)
- [ ] 활성 알람이 있을 때 `SIL` 을 누르면 이 브라우저의 버튼만 눌린 모양이 된다. 다른 브라우저는 그대로다.
- [ ] SIL 을 누른 뒤 새 알람이 오거나 같은 알람이 또 일어나면(`×N` 증가) 눌린 모양이 풀린다.
- [ ] 알람 목록은 SIL 로 바뀌지 않는다.

## C. 권한
- [ ] `oper` 와 `mngr` 모두 `ACK` 가 된다. 백엔드 로그에 `알람 ACK: [...] (oper)` 처럼 계정이 남는다.
- [ ] 로그아웃한 상태에서 `curl -X POST -H 'Content-Type: application/json' -d '{}' http://localhost:8000/api/alarms/ack` 는 401 이다.

## D. 이력 파일 (`data/alarms/`)
- [ ] 비상정지를 여러 번 눌러 `×N` 으로 묶여도 이력에는 누를 때마다 `repeated` 줄이 쌓이고 줄마다 시각이 다르다 (다른 알람이 사이에 끼어도 시간순).
- [ ] 모든 줄은 **시간순으로 쌓이고** 기존 줄은 바뀌지 않는다.
- [ ] 줄에 `count`, `acked_by`, `acked_at` 가 있다 (16개 키). 형식은 `../reference/alarm-history-format.md`.
