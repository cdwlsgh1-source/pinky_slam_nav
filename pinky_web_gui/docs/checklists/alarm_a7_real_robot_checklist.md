# 알람바 Step A7 실물 확인 체크리스트 (사용자 수행)

> 역할: Alarm 화면 History 탭(Step A7)을 **실제 로봇의 알람으로 확인하는** 순서. mock 으로는 `tests/test_alarmquery.py`(묶기·필터·페이지·`Uncleared`/`Active`·CSV·API)와 `tests/verify_alarm_history_ui.py`(화면, 알람 330건)가 통과했다. 이 문서의 항목은 아직 실제 로봇에서 실행되지 않았다.
> 규칙은 `../interfaces.md` 6-7절 "Alarm 화면 History 의 상태", 계획은 `../prd/Pinky 알람바 개선 — 단계별 PRD.md` Step A7. 이력 파일 형식은 `../reference/alarm-history-format.md`.

> 로봇이 움직일 수 있는 항목은 주변을 비우고 전원 스위치에 손이 닿는 곳에서 한다.

## 사전 조건
- [ ] 관제 PC: `export ROS_DOMAIN_ID=50` 후 `.venv/bin/python -m backend.main` (**`--mock` 없이**). 브라우저로 `http://localhost:8000/`, `mngr` 또는 `oper` 로 로그인.
- [ ] 알람을 몇 개 만든다: 로봇 한 대의 전원을 껐다 켜기(`ROBOT_OFFLINE`), 허용되지 않은 지점으로 이동 시도(`CMD_REJECTED`), 브릿지를 끈 채 `start`(`CMD_SEND_FAILED`).

## A. 화면과 배지
- [ ] 왼쪽 메뉴의 `Alarm` 버튼을 누르면 작업 영역 대신 History 탭이 나온다. 위의 알람바와 비상 정지는 그대로 보이고 눌린다.
- [ ] 메인 화면에서도 `Alarm` 버튼 옆 배지에 지금 활성인 알람 수가 보이고, HH/H 가 있으면 빨강이다. 알람이 모두 해소되면 배지가 사라진다.
- [ ] 새로고침(F5)해도 보던 화면(메인 / 로그 / Alarm)과 탭(History / Catalog)이 유지된다.

## B. 목록
- [ ] 방금 만든 알람이 한 건씩 나온다 (같은 알람을 ACK 전에 여러 번 일으키면 한 행의 횟수가 늘고, ACK 한 뒤에 또 일으키면 새 행).
- [ ] 지금 활성인 알람이 맨 위에 고정되고(초록 줄), 조건이 풀리면(로봇 전원 복구, 명령 성공) 그 자리에서 `해소` 로 바뀐다. 다른 브라우저 탭에서도 같다.
- [ ] 해소된 알람은 `해소` 시각과 지속 시간이, ACK 한 알람은 `확인` 칸에 계정과 시각이 나온다.
- [ ] 어제 이전 알람은 시작 날짜를 바꾸고 `Apply` 하면 나온다. 목록이 200건을 넘으면 `Load more` 가 보이고 누르면 더 오래된 알람이 이어서 나온다.

## C. 필터와 검색
- [ ] 로봇, 레벨(여러 개 체크), 상태, 코드(자동 완성), 메시지 검색이 서버 결과로 적용된다. `Reset` 은 오늘·전체로 돌아간다.
- [ ] 검색은 메시지와 사유(`detail`) 문구에서 찾는다 (예: `domain_bridge`).

## D. 서버를 재시작해도
- [ ] 알람이 활성인 채로 서버를 끄고(Ctrl+C) 다시 켠 뒤 History 를 보면 그 알람이 **`해소 기록 없음`**(주황 글씨)으로 나오고, 새로 일어난 알람과 번호(`id`)가 겹쳐도 서로 다른 행이다. `활성` 은 재시작 뒤에 다시 일어난 알람만이다.
- [ ] 이력 폴더(`data/alarms/`)에는 서버를 끈 시각의 `cleared` 줄이 쓰이지 않았다 (`tail data/alarms/<가장 최근 파일>`).

## E. 상세와 파일
- [ ] 행을 누르면 타임라인(발생 → 반복 N회 → 확인 → 해소의 시각과 계정), 전체 문구와 사유(긴 사유는 줄바꿈), 코드, 이력 파일 이름이 나온다. 이력 파일(`data/alarms/*.jsonl`)의 줄과 같다.
- [ ] 위 요약 한 줄(저장 폴더, 파일 수, 알람 수)이 `ls data/alarms` 와 맞고 `Show files` 로 파일별 건수가 보인다 (삭제 버튼은 없다).

## F. CSV
- [ ] `Export CSV` 로 내려받은 파일을 스프레드시트(Excel, LibreOffice)로 열면 한글이 깨지지 않고 열 제목이 `발생, 로봇, 레벨, 코드, 메시지, 상태, …` 이다. 시각은 `YYYY-MM-DD HH:MM:SS`, 파일 이름에 기간이 들어 있다.
- [ ] 조건(로봇, 레벨 등)을 건 뒤 내려받으면 그 조건의 알람만 들어 있다.

## G. 권한
- [ ] `oper`(operator) 로도 History 를 보고 CSV 를 받을 수 있다. 로그인하지 않으면 401 로 화면이 로그인을 요구한다.

결과(통과/실패, 이상한 화면 캡처, 백엔드 로그)를 알려 주면 이 문서와 PRD 구현 메모에 반영한다.
