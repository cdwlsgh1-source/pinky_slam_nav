# 알람바 Step A3 실물 확인 체크리스트 (사용자 수행)

> 역할: 알람 소리와 소리 설정(Step A3)을 **실제 스피커와 실제 로봇 알람으로** 확인하는 순서. 소리는 자동으로 들을 수 없어서 mock 시험(`tests/test_alarmsound_js.py`, `tests/verify_alarm_sound_ui.py`)은 재생 함수가 불린 횟수만 센다. 이 문서의 어떤 항목도 아직 사람이 들어 보지 않았다.
> 규칙은 `../interfaces.md` 6-7절 "알람 소리", 계획은 `../prd/Pinky 알람바 개선 — 단계별 PRD.md` Step A3.

> 로봇이 움직일 수 있는 항목(비상정지 실패 만들기 등)은 주변을 비우고 전원 스위치에 손이 닿는 곳에서 한다. 소리를 크게 켜기 전에 음량 슬라이더를 낮춰 둔다.

통과/실패와 이상한 소리·화면 캡처를 알려 주면 된다.

## 사전 조건
- [ ] 관제 PC에서 GUI 서버를 띄운다 (실제 로봇이면 `--mock` 없이, 소리만 볼 거면 `--mock`). Chrome 권장, 스피커가 켜져 있다.
- [ ] `pinky_web_gui/config/sounds/` 에 소리 파일을 둔다 (mp3/wav/ogg, 1MB 이하). 레벨마다 다른 파일을 쓰려면 2~4개. 서버를 다시 켤 필요는 없다.

## A. 소리 설정 화면과 시험 재생
| # | 항목 | 방법 | 기대 | 결과 |
|---|---|---|---|---|
| 1 | 첫 클릭 전 안내 | 브라우저를 새로 열어 아무것도 누르기 전에 알람바를 본다 | 칩 줄에 주황색 `Click to enable alarm sound` | |
| 2 | 안내 해제 | 화면 아무 곳이나 한 번 누른다 | 안내가 사라진다 | |
| 3 | 설정 열기 | 왼쪽 메뉴의 `Sound` 버튼 | `Alarm sound` 창: 켜기, `Volume`, `Repeat interval (s)`, 레벨(HH/H/L/LL)별 On, `Sound file`, `Test`/`Stop`. 문구가 모두 영문. 둔 파일이 `Sound file` 목록에 나온다 | |
| 4 | 합성음 구분 | 파일을 고르지 않은 채(`Fallback beep`) HH, H, L, LL 의 `Test` 를 차례로 | 레벨마다 다른 소리 (HH 가장 높고 빠른 4연타, H 2연타, L 한 번, LL 낮은 한 번). 반복 주기마다 되풀이 | |
| 5 | 정지 | `Stop` 또는 창 닫기 | 소리가 멈춘다. `Test` 를 눌러도 알람바에는 아무 행도 생기지 않는다 | |
| 6 | 파일 재생 | 레벨 하나에 파일을 골라 `Test` | 고른 파일이 재생된다 (상태줄에 `playing <파일>`). 파일을 바꾸면 바로 바뀐 소리로 | |
| 7 | 음량 | 슬라이더를 움직이며 `Test` | 파일과 합성음 모두 음량이 바뀐다 | |
| 8 | 반복 주기 | 주기를 1 과 10 으로 바꾸며 `Test` | 그 간격으로 되풀이. 0 이나 999 를 넣으면 1 / 60 으로 맞춰진다 | |

## B. 실제 알람과 소리
| # | 항목 | 방법 | 기대 | 결과 |
|---|---|---|---|---|
| 9 | 알람이 오면 울림 | 로봇 한 대의 전원을 끄거나 브리지를 끄고 명령을 보내 H/L 알람을 만든다 | 알람 레벨에 맞는 소리가 나고 주기마다 반복된다 | |
| 10 | 가장 급한 소리 | HH 알람(브리지를 끈 채 `비상 정지`)과 H/L 알람이 같이 있을 때 | HH 소리가 난다. HH 만 ACK 하면 남은 알람의 소리로 바로 바뀐다 | |
| 11 | SIL | 소리가 나는 중에 `SIL` | 이 브라우저의 소리만 멈춘다. 두 번째 브라우저는 계속 울린다 | |
| 12 | 새 알람이 오면 SIL 해제 | SIL 상태에서 다른 알람을 만든다 | SIL 이 풀리고 소리가 다시 난다 | |
| 13 | ACK | 소리가 나는 중에 `ACK` | 소리가 멈춘다 (활성 알람은 `Acknowledged` 로 남음) | |
| 14 | 해소 | 조건을 되돌려 알람을 해소 | 소리가 멈춘다 | |
| 15 | info 는 무음 | 정상 명령(`순찰 시작` 등)을 보낸다 | `Command ... sent` 행만 생기고 소리는 없다 | |
| 16 | 전체 끄기 | 설정에서 `Alarm sound on` 을 끄고 HH 알람을 만든다 | 소리는 없지만 HH 행(굵은 빨강)은 알람바에 그대로 보인다 | |
| 17 | 레벨 끄기 | 한 레벨의 `On` 을 끈다 | 그 레벨 알람만 소리가 없다 | |

## C. 파일이 없거나 실패할 때 (소리 없이 넘어가지 않는다)
- [ ] 레벨에 파일을 고른 뒤 `config/sounds/` 에서 그 파일을 지운다. 설정 창을 다시 열면 `<파일> (missing)` 으로 보이고, 그 레벨의 알람/`Test` 는 **합성음**이 난다 (상태줄 `fallback beep (file missing: ...)`).
- [ ] 소리가 아닌 파일을 `.wav` 로 이름만 바꿔 두고 고른다. `Test` 가 합성음으로 대체된다 (`file failed: ...`).
- [ ] `config/sounds/` 에 1MB 넘는 파일이나 `.txt` 를 두면 목록에 나오지 않는다.

## D. 저장
- [ ] 설정을 바꾸고 새로고침(F5)해도 유지된다. 다른 브라우저(또는 시크릿 창)는 기본값에서 시작한다 (브라우저별 저장).
- [ ] (선택) 시크릿 창처럼 저장소가 막힌 환경에서도 설정 창과 `Test` 가 동작한다 (새로고침하면 기본값으로 돌아감).
