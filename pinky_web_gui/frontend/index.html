로봇

시스템 (프로세스)

    브릿지와 zone_manager 는 이 PC 에서, bringup 과 map 은 SSH 로 로봇에서 실행합니다. 터미널에서 직접 켠 프로세스는 여기서 끌 수 없습니다. 로그인(operator)이 필요합니다.

    경로 이동 (goto)

    지도의 포인트(P1~P7)를 클릭하면 경로 끝에 추가됩니다. 구역 문(RED*)과 락은 로봇이 알아서 처리합니다. 지도의 경로 버튼을 켜면 로봇의 경로 선을 그리며(기본 꺼짐), 이 선은 지도의 벽을 피하는 최단 경로를 계산한 추정이라 Nav2 의 실제 경로와 조금 다를 수 있습니다.

      경로가 비어 있습니다.

      오버레이 (LiDAR)

      켠 로봇만 서버가 /scan 을 구독합니다 (5Hz, 점 3개당 1개). 점은 로봇의 tf(map → 센서)로 지도에 그립니다. tf 를 못 구하면 AMCL 위치와 설정의 보정 각도(scan.yaw_offset_deg)로 대신 그리며, 이때는 센서 방향이 어긋날 수 있습니다. 어느 쪽인지는 로봇 이름 옆에 표시됩니다.
